# مستندات فارسی

کتاب آماده را بخوانید: [`YouTube_Downloader_Tutorial_fa.pdf`](YouTube_Downloader_Tutorial_fa.pdf).

برای ساخت دوبارهٔ آن، فایل `main.tex` را در TeXstudio باز کنید، موتور **XeLaTeX**
را انتخاب کنید و برای به‌روزشدن فهرست مطالب دو بار خروجی بگیرید. فایل `config.tex`
شامل قلم‌ها، رنگ‌ها، پیوندها، تنظیم کدها و کادرهای مشترک است. هشت فایل پوشهٔ
`chapters/` متن آموزش را نگه می‌دارند و از `main.tex` فراخوانی می‌شوند؛ فقط
`main.tex` را کامپایل کنید.

این نسخه از XePersian و جهت راست‌به‌چپ استفاده می‌کند. قلم نخست `IRANSansX` است و
در نبود آن، `B Nazanin` و سپس `Noto Naskh Arabic` انتخاب می‌شوند. کدها و
دستورها همیشه چپ‌به‌راست و با قلم `DejaVu Sans Mono` نمایش داده می‌شوند. برای
کدهای کوتاه داخل متن فارسی از فرمان `\code{...}` استفاده کنید تا جهت و ترتیب
نویسه‌ها درست بماند.

همهٔ صفحه‌های محتوایی یک پانوشت کوچک و قابل‌کلیک برای شبکه‌های اجتماعی دارند و
همین پیوندها روی جلد نیز آمده‌اند. برای پیش‌نیازها و رفع اشکال، [راهنمای ساخت
مستندات](../README.md) را ببینید.
